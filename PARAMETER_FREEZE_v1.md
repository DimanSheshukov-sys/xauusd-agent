## A. Elliott / swings (gaps A1–A6)

| Параметр | Значение | Обоснование (a priori, не по результату) |
|---|---|---|
| `SWING_K` (порог разворота) | **2.0 × ATR(14, M15)** | Swing должен быть масштаба H1 (refinement по §4), а не M15-шума. Замер: при k=2.0 медианный свинг = 6 баров ≈ 1,5 часа → совпадает с H1 |
| `SWING_MIN_BARS` | **1** (отключён) | Реализация min_bars=3 приводила к вечной блокировке подтверждения (115 534 блокировки на 116 330 баров). Единственный шумовой фильтр — ATR-порог |
| `SWING_ATR_N` | 14 | Стандарт TV/Уайлдер |
| ATR для порога | значение **на баре-экстремуме** | Причинно: известно к моменту подтверждения |
| Подтверждение пивота | `low[i] ≤ hi_extreme − K·ATR` (и зеркально) | Классический causal ZigZag; пивот получает `confirm_idx = i` |
| Wave degree | один рабочий уровень (M15-свинги), вложенность не используется | Упрощение v1, зафиксировано явно |
| Альтернативные counts | не строятся; берётся последняя подтверждённая последовательность из 5 пивотов | §37 policy resolution: один primary, альтернатива только при независимом обосновании — в v1 отсутствует |
| Determinism | online == offline (тест `tests/test_causality.py`, T1/T2/T3) | G01 |

**Sensitivity-набор (не выбор лучшего!):** k ∈ {1.5, 2.0, 3.0}. Публикуются все три; первичный — k=2.0.
Отчёт по непервичным k помечается как robustness check, решение по нему не принимается (§70: нельзя hard-code по удачной серии).

## A′. Правила валидности импульса (причинно проверяемые)

```text
R1  W2 не ретрейсит 100% W1        L2 > L0  (up) / L2 < L0 (down)
R2  W4 не заходит на территорию W1  L4 > H1  (up) / L4 < H1 (down)
R3  W4 короче W3                    ret4 < 1
R4  «W3 не самая короткая»          PENDING — причинно непроверяема до завершения W5
```

R4 сознательно **не** применяется как фильтр: иначе CLASS A (W3/W1 < 1) из §8 был бы недостижим,
а §9 объявляет non-extended W3 сильнейшим классом. Нарушение R4 постфактум = FAILED FIFTH (§6, research only, не торгуется).

## C. Trigger и invalidation (gaps C9–C11)

| Параметр | Значение |
|---|---|
| Trigger | **причинный Donchian-breakout**: LONG — `close[i] > max(high[i-8..i-1])`; SHORT — `close[i] < min(low[i-8..i-1])`. Текущий бар в канал не входит |
| `TRIGGER_DONCHIAN_N` | 8 баров M15 (= 2 часа) |
| ТФ trigger | M15 (§29). H1 — только setup refinement, M5 — не используется в v1 |
| Structural invalidation (§11) | LONG: `close < L4`; SHORT: `close > H4` |
| `SETUP_MAX_AGE` | 200 баров M15 (~4 торговых дня). После — setup устарел → S19 NO_TRADE |
| Совместимость SL (§26) | **`tight`**: SL не может быть шире structural invalidation (LONG: `SL ≥ L4`). Иначе WAIT_RISK. Расширять SL ради сохранения сделки запрещено (§26) |
| Sensitivity по §26 | профиль `G_PROD_WIDE` (обратная трактовка) — только как диагностика неоднозначности канона |

## G. Методология валидации (gaps G26–G30)

| Параметр | Значение |
|---|---|
| SAMPLE SUFFICIENT (§60) | **N ≥ (1.96 · SD_per_trade / expectancy)²** — формула, не константа. При SD≈1.24R: для +0.09R → N≥729; для +0.35R → N≥50 |
| Значимость | t = expectancy·√N / SD, двусторонний p; принимается p < 0.05 |
| Rolling stability (§62) | окна 20/30/50 сделок; порог pass: **≥60 % окон с expectancy > 0** и медианный PF > 1.0 |
| Walk-forward (§45) | параметры frozen → обучающих окон нет; вместо них последовательные **90-дневные OOS-окна** по всему периоду. Любая калибровка запрещена (§46) |
| Множественные сравнения | все конфигурации (branches × geometry × k) публикуются **полным списком**; лучшая не выбирается. Для вывода о promotion требуется pre-registered гипотеза + отдельный OOS |
| Разделение датасетов | результаты §49–53 канона получены на прежнем датасете прежним кодом — с моим прогоном **не пересекаются по реализации**, но пересекаются по периоду; независимыми не считаются |
| News filter (§43) | в v1 не реализован (нет исторического календаря без look-ahead). Помечено как ограничение: в периоды FOMC/NFP сделки не исключаются |
