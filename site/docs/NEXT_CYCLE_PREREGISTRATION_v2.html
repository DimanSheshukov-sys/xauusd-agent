3. PRE-REGISTERED гипотезы для цикла v2

Каждая гипотеза тестируется только на новых данных (см. §4). Никаких изменений по итогам

исследовательского прогона 2022–2026 не вносится — этот период объявляется used research sample.

H1 — Execution geometry: R должен быть ≥ 2.5 ATR(M15) либо ТФ исполнения H1


Правило: SL = 2.5 ATR(exec TF), TP = 1.0R, max hold 96 баров exec TF
Основание: O1, O2, O4, O10
Критерий ACCEPT: Exp net > 0 AND p < 0.05 AND rolling ≥60% окон Exp>0 AND N ≥ (1.96·SD/Exp)²
Критерий REJECT: Exp net ≤ 0 OR p ≥ 0.05

H2 — LONG-only: SHORT-ветки перевести в P0 до независимого подтверждения


Правило: B05/B06/B07 = DISABLED (не торгуются); LONG-ветки B01–B04 активны
Основание: O5 (все SHORT-ветки отрицательны, одна значимо)
Критерий ACCEPT: LONG-only Exp net > 0, p < 0.05, rolling PASS
Обязательное условие: отдельно зафиксировать, что SHORT отключён НЕ потому, что убыточен
  на research sample, а потому, что его evidence (N=15/20/29) не проходит порог sample sufficiency

H3 — Приоритет B04 (Extended W3 + RSI momentum LONG)


Правило: B04 получает приоритет 1, B02 — приоритет 2, B01 — 3; B03 (W3 class A) — CONTEXT_ONLY
Основание: O8, O9, O6
Критерий ACCEPT: B04 Exp net > 0, p < 0.05, N ≥ 50 на новых данных
Запрет: не повышать статус B04 до P3 по одному прогону (§63: 50+ = FULL CALIBRATION, не promotion)

H4 — W3 CLASS A не используется как приоритет


Правило: §13 high-conviction (W3/W1 < 1) понижается до diagnostic-only
Основание: O6
Критерий: если на новых данных CLASS A снова покажет PF ≥ 1.8 при N ≥ 40 — гипотеза отклоняется,
  §13 восстанавливается (симметричное условие, чтобы не подтвердить H4 любой ценой)

H5 — Cost-aware допуск ветки (новое правило, в каноне отсутствует)


Правило: ветка допускается к trade только если round_trip_cost / R ≤ 0.05 (5% от R)
Основание: O1, O4
Статус: ПРЕДЛАГАЕТСЯ как дополнение к G14 (R:R) — требует правки канона (§10 G14a)

H6 — Regime-срез в обязательной отчётности


Правило: к §54 добавить разбивку по regime (D1 above/below EMA200) и по году
Основание: O11
Статус: методологическое, не влияет на торговую логику

6. Чего делать нельзя (напоминание самому себе и следующему агенту)

  • Промоутить G_BASE47 в production на основании этого прогона: данные PROXY (PAXG), период уже использован.
  • Выбирать k=1.5 или 3.0 потому, что они «почти такие же»: первичный k=2.0 зафиксирован a priori.
  • Считать, что O10 (GC=F H1) — независимое подтверждение: период пересекается с research sample.
  • Отключать SHORT «потому что убыточно» без фиксации, что его evidence просто не дотягивает до sample sufficiency.
  • Менять cost model после получения результатов.
  • Объединять directional evidence и exit evidence (§17) — геометрия тестируется как единый frozen-профиль.
