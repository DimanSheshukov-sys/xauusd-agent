2. Замороженная конфигурация v2 (полностью)


DATA          : XAUUSD M15 (спот) — до его получения: PAXGUSDT M15 без выходных [PROXY]
SWING         : causal ZigZag, K = 2.0 × ATR(14, M15), min_bars отключён, ATR на баре-экстремуме
STRUCTURE     : IMPULSE_W5 (W1–W4 подтверждены) → forecast W5; ABC/Failed Fifth не торгуются
VALIDITY      : R1 W2 не ретрейсит 100% W1 • R2 W4 не заходит на территорию W1 • R3 W4 короче W3
                R4 «W3 не самая короткая» = PENDING (причинно непроверяема)
W3 CLASS      : A <1 | B 1–1.618 | C ≥1.618 (измеряется на confirm_idx пивота P4)
BRANCHES      : B01_LONG_CORE (Fib ON), B02_LONG_EMA200_FIBOFF, B04_LONG_EXTW3_RSI (RSI H1 > 50)
PRIORITY      : B04 → B01 → B02  (специфические раньше общих; на системный итог не влияет)
REGIME (G07)  : D1 close > D1 EMA200 (последний ЗАКРЫТЫЙ дневной бар) — REQUIRED для LONG
CONFIRM (G08) : B04 — RSI(14, H1) > 50; Fib ON для B01: 0.382 ≤ ret2 ≤ 0.786 и 0.236 ≤ ret4 ≤ 0.5
EVENT (G08a)  : вход запрещён в [FOMC/NFP − 2h … +2h]
TRIGGER (G10) : причинный Donchian(8) breakout на M15 (close за max/min предыдущих 8 баров)
INVALIDATION  : LONG — close < L4; SL-совместимость `tight` (SL ≥ L4), иначе WAIT_RISK
EXECUTION     : entry = open[i+1]; SL = 2.5 × ATR(14, M15); TP = 1.0R; max hold = 96 баров M15
OHLC RESOLVE  : TP и SL в одном баре → SL FIRST (§28)
COSTS         : 0.40 USD спред + 0.06 USD комиссия/сторону = 0.52 USD round-trip; gate G14a cost/R ≤ 0.05
SETUP AGE     : ≤ 200 баров M15, иначе S19 NO_TRADE
CONTEXT ONLY  : Wyckoff-флаг, W3 CLASS A, Schiff (не реализован), macro/DXY

5. Что осталось открытым

  1. Спот XAUUSD M15 — блокер P3 (прокси непригоден для structural-валидации: шум базиса ≈ 2 ATR).
  2. CPI и прочие high-impact события не покрыты фильтром (нет исторического календаря без внешнего API).
  3. Wave degree / вложенность волн (v1–v2: один уровень).
  4. Альтернативные counts (§37) — политика не формализована.
  5. Swaps/rollover в cost model.
  6. Правки канона, которые нужны для непротиворечивости: §10 (добавить G14a cost/R), §25/§82 (геометрия),

§26 (трактовка tight), §58 (статусы SHORT и W3 CLASS A), §60 (формула SAMPLE SUFFICIENT).

ADDENDUM v2.2 — ФРАКТАЛЬНЫЕ СТЕПЕНИ ВОЛН (H4 / M15 / M5 / M1) — PRE-REGISTERED

Дата: 2026-09-16 • Статус: анализ и отображение; торговые правила НЕ изменены (канон §63–65: любая

торговая применение степеней требует отдельного walk-forward/OOS).

Модель степеней

СтепеньТаймфреймРоль
D2 (primary)H4основные волны импульса/коррекции
D1M15субволны текущей волны H4; execution-степень канона
D0M5суб-субволны текущей волны M15
D-1 (micro)M1микроволны текущей волны M5

Правила разметки (заморожены)

  1. Каждая степень размечается независимо причинным ZigZag с порогом K = 2.0 × ATR(14) своего ТФ

(поэтому на мелких ТФ автоматически получаются мелкие субволны);

  1. Вложенность выводится причинно по времени: текущая нога степени D(k) является отрезком, внутри

которого живёт вся разметка степени D(k−1); цепочка читается как

H4:W3 ⊃ M15:W4 ⊃ M5:W2 ⊃ M1:W5;

  1. текущая нога степени = волна с номером piv.length (5 пивотов → W5 идёт сейчас; 3 пивота ABC → C);
  2. согласованность (diagnostic): все 4 степени одного направления → «согласованы»;

иначе «разнонаправлены». Это контекст, не гейт и не сигнал;

  1. invalidation и trigger каждой степени — свои (по своему ZigZag/Donchian);
  2. отображение: панель «Волны по таймфреймам» на LIVE + цепочка вложенности.

Что запрещено

  • использовать согласованность степеней как mandatory gate или trigger без нового pre-registration

и walk-forward (§68–69);

  • менять execution-степень канона (M15) и геометрию SL/TP;
  • размечать степень по будущим барам (каждая степень использует только свои закрытые бары).

Кандидат для будущей валидации (зафиксирован сейчас, не применяется)

  • H-MTF-ALIGN: входить только при согласованности H4+M15+M5 по направлению → требует walk-forward 365/90

на каждой степени и сравнения с текущим базовым правилом.
